# AI GeoSurvey — DEM Stage 1.1

Учебное браузерное приложение для просмотра GeoTIFF DEM, базового анализа рельефа и отдельной демонстрации распознавания обычных объектов.

## Что нового в версии 1.1
- Определение EPSG из GeoTIFF GeoKeys (если сведения присутствуют).
- Для географических координат EPSG:4326 расстояния между пикселями приблизительно переводятся в метры с учётом средней широты участка.
- Уклон и экспозиция используют вычисленный размер пикселя.
- Настройки Hillshade: азимут, высота солнца и контраст.
- В интерфейсе отображаются система координат и использованный размер пикселя.

## Запуск локально
1. Распакуйте архив.
2. Откройте папку `ai-geosurvey-dem`.
3. Запустите `python -m http.server 8000`.
4. Откройте `http://localhost:8000`.

Для загрузки CDN-библиотек нужен интернет.

## Обновление GitHub Pages
Замените в корне существующего репозитория `ai-geosurvey-dem` файлы `index.html`, `style.css`, `app.js`, `README.md` и `.nojekyll` файлами из этой папки. Сохраните изменения в ветке `main`. GitHub Pages должен оставаться настроенным на `main` и `/ (root)`.

## Ограничения точности
- Перевод EPSG:4326 в метры — локальное приближение по средней широте, не полноценная перепроекция. Для инженерных, кадастровых и научных расчётов перепроецируйте DEM в подходящую метрическую систему координат (для Нидерландов часто используют RD New / EPSG:28992) и проверьте вертикальные единицы.
- Для проецированных CRS предполагаются метры; проверьте метаданные исходного GeoTIFF.
- Если GeoTIFF не содержит GeoKeys или масштаба пикселя, уклоны могут быть условными.
- Hillshade — учебная визуализация, не геодезический продукт.
- COCO-SSD распознаёт ограниченный набор обычных объектов и не предназначен для распознавания картографических условных знаков.
