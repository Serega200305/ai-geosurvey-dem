# AI GeoSurvey — этап 1

Учебное браузерное приложение для просмотра GeoTIFF DEM (цифровой модели высот), расчёта базовой статистики и простых производных визуализаций. Отдельно сохранён демонстрационный модуль распознавания обычных объектов на изображениях.

## Возможности
- Загрузка одноканального GeoTIFF DEM в браузере.
- Карта высот с цветовой шкалой.
- Минимальная, максимальная и средняя высота, перепад, число валидных ячеек.
- Приближённая карта уклонов и экспозиции по соседним пикселям.
- Условная отмывка рельефа.
- Экспорт текущей визуализации в PNG и статистики в CSV.
- Отдельный модуль COCO-SSD для распознавания обычных объектов на изображении.

## Запуск локально
Можно открыть `index.html` через локальный веб-сервер (рекомендуется, а не file://). Например, в папке проекта:
```bash
python -m http.server 8000
```
Затем открыть http://localhost:8000.

## Публикация на GitHub Pages
1. Создайте отдельный репозиторий, например `ai-geosurvey-dem`.
2. Загрузите в корень `index.html`, `style.css`, `app.js`, `README.md`, `.nojekyll`.
3. Откройте Settings → Pages.
4. В Build and deployment выберите `Deploy from a branch`.
5. Branch: `main`; Folder: `/ (root)`; нажмите Save.
6. Дождитесь публикации и откройте URL, который GitHub покажет в Pages.

## Ограничения и важные замечания
- Обработка происходит локально в браузере; файл DEM не загружается на сервер.
- Библиотека GeoTIFF.js и TensorFlow.js загружаются с CDN, поэтому для работы нужен интернет.
- Для расчёта уклона используются ModelPixelScale из GeoTIFF. Для корректного физического результата DEM должна иметь горизонтальные координаты в метрах, а значения высот — в метрах или согласованных единицах. Географические координаты в градусах не перепроецируются автоматически.
- Код является учебным прототипом: не выполняет полноценную проверку CRS, геоидальной/эллипсоидальной высоты, поворота/сдвига растра, вертикального датумa или точности DEM.
- Экспозиция и hillshade реализованы упрощённо; ориентация осей и параметры освещения требуют проверки для конкретных данных.
- Горизонтали, профиль и полноценная геопривязка будут добавлены на следующих этапах.
- COCO-SSD распознаёт ограниченный набор бытовых классов (например, людей, машины, велосипеды), но не является моделью анализа рельефа и не распознаёт специализированные топографические условные знаки.
- Не использовать учебные результаты для инженерных или кадастровых решений без независимой проверки.

## Структура
- `index.html` — интерфейс.
- `style.css` — оформление.
- `app.js` — чтение DEM, анализ и распознавание изображений.
- `.nojekyll` — отключает обработку сайта Jekyll в GitHub Pages.
